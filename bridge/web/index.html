Measure power

Holds the buddy in one state so you can measure its current with a power profiler on the battery lead. While a mode is held the buddy ignores Claude, makes no sound of its own, and goes back to normal by itself after 30 minutes or on a restart. The hours it covers are marked in the battery log. To measure advertising without a connection, stop the bridge while the buddy is in the mode you want.

Try a battery (for a buddy without a fuel gauge)

Pretends there is a battery so the battery screen and the low-battery warning can be tried. Only works on a firmware built with battery simulation (CONFIG_BUDDY_BATTERY_SIMULATION), or with the bridge's --simulate mode.

Firmware update

Choose the update file the build made (dfu_application.zip, or a .signed.bin) and send it. The buddy receives the file over Bluetooth and restarts with the new firmware; it stops following Claude for a minute or so. The file must be signed with the key your buddy was set up with.
